Mario Prøter Photography – gratis statische Webseite

1. Öffne index.html im Browser.
2. Ersetze deine-email@beispiel.no in index.html durch deine echte E-Mail.
3. Ersetze die Galerie-Platzhalter später durch <img>-Elemente mit deinen Fotos.
4. Gratis veröffentlichen:
   - GitHub Pages
   - Cloudflare Pages
   - Netlify (Free Tier, sofern verfügbar)
